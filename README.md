# Internal Frontier

Internal Frontier clothing storefront and enquiry API.

The storefront is available from `index.html`. Customers can filter and search the collection, select sizes, save pieces to an enquiry bag, and send the selection to the shop on WhatsApp.

## Backend

From the `backend` directory, install dependencies with `npm install` and start the API with `npm start`. The API listens on port `3000` by default and exposes `/` and `/health`. Set `DATABASE_URL` for the PostgreSQL health check.
